# stack-rn.md — React Native

Load this only when the project uses React Native (Expo is the default).

- Use Expo for new apps unless a native module forces a bare workflow.
- TypeScript strict mode; same component/state rules as `stack-react.md`.
- Tests: Vitest for logic; device tests only for release-critical flows.
- Keep platform-specific code behind small adapters.
- Never commit native build output (`android/`, `ios/` are generated by Expo).
